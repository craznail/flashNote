# flashNote UI 设计基准

本目录的图片是 App 页面的视觉参考。图中 iOS 状态栏和系统导航区域不属于 App 页面，Android 使用系统原生状态栏与导航栏。极简模式以当前产品要求为准：只展示笔记原始截图，上下滑动切换相邻笔记图片。

| 文件 | 页面与状态 |
| --- | --- |
| `home.png` | 笔记首页、最近笔记、搜索、主导航 |
| `notes-list.png` | 全部笔记、筛选排序、批量选择与删除确认 |
| `note-detail.png` | 笔记详情、详情摘要、底部操作 |
| `minimal-detail.png` | 历史极简阅读稿；其中的文字和控件已被图片浏览模式取代 |

整理页和设置页沿用以上四张图的白底、蓝色强调、浅色卡片、字体层级及控件风格。悬浮球本体、菜单和反馈动画沿用现有设计。
